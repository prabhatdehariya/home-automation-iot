# Home Automation System using Voice and Mobile Control

## Overview
This project implements a smart home automation system using ESP32 and IoT technology.

The system allows users to control home appliances using:
- Mobile phone
- Voice commands
- Wi-Fi communication

---

## Features
- Wireless appliance control
- Voice assistant integration
- Mobile app control
- Low power consumption
- Real-time switching

---

## Components Used
- ESP32
- Relay Module
- Bulb/Fan
- Breadboard
- Jumper Wires
- Smartphone

---

## Software Used
- Arduino IDE
- Blynk IoT Platform

---

## Working Principle
1. ESP32 connects to Wi-Fi.
2. Mobile app sends commands.
3. ESP32 processes commands.
4. Relay switches appliances ON/OFF.
